# ImmXrsive brand artwork

Extracted unchanged (vector paths) from the official *Immxrsive Logo Style Guide* (Adobe InDesign, July 2024):

| File | Source page | Use |
|---|---|---|
| `immxrsive-logo-reverse.svg` / `.png` | p.4, reverse horizontal logo | Dark backgrounds (site header/footer). Navy box removed only. |
| `immxrsive-logo.svg` | p.3, primary horizontal logo | Light backgrounds. |
| `immxrsive-icon-reverse.svg` | p.7, reverse XR icon | Small marks on dark backgrounds. Navy box removed only. |
| `immxrsive-icon-tile.svg` | p.7, XR icon on dark blue | Favicon / app icon. |

Guide rules: use only provided artwork; do not alter typography, arrangement, colours or proportions; keep clear space equal to the cap height of "I" on all sides; minimum digital width 72px (horizontal logo).

The 180px, 192px and 512px `immxrsive-icon-*.png` files are lossless raster exports of `immxrsive-icon-tile.svg` for Apple/app icon support. The supplied SVG artwork is unchanged; exports preserve the whole tile, colours and proportions.
