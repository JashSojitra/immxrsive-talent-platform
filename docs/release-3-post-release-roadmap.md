# Post-R3 roadmap — explicitly deferred

Date: 2026-11-04. This is a scope boundary, not authorization to implement or spend on services.

**AutoDemo is deferred beyond assessed R3.** GitHub-to-playable preview generation, repository checkout/build execution, preview runners, sandbox infrastructure, hosting and automated deployment are not part of R3 closure. The current importer proposes public repository metadata only. A repository URL does not become a playable URL; humans supply existing playable and fallback evidence independently.

**All R3.1 features are deferred.** No R3.1 work, preview generation, runners or broad redesign is included in this proposed patch. Any later work needs its own requirements, safety/operational review, tests and explicit authorization. It must not delay resolving required R3 evidence, adapter and assessed-version gaps.

Possible later improvements for separate prioritization include richer safe import diagnostics, optional authenticated GitHub quota and partial metadata recovery, expanded advisory duplicate search, broader browser/device accessibility checks and richer relationship history. These are optional ideas, not confirmed production root causes or R3 requirements.
